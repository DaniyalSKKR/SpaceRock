Impactor-2025 Simulator — Overview

This prototype demonstrates an integrated UI for exploring asteroid impact scenarios using NASA and USGS data. It focuses on clarity and accessibility while allowing room for more rigorous physics backends and richer visualizations (Three.js, Leaflet, D3).

Where to plug real data
  • NASA NEO API: Pull orbital elements and physical parameters in your Django view/backend, then send them to the template via context or an API endpoint.
  • USGS: Use elevation (DEM), tsunami zones, and seismic layers for map overlays (serve tiles or vector tiles to the front end).
  • Back-end simulation: Implement orbital propagation and impact physics server-side (Python), return results to client for visualization & sharing.
Accessibility & UX

All controls include labels, keyboard focus, and descriptive text. For production, add ARIA live regions for simulation updates, colorblind palettes, and keyboard-only paths.
