Impactor-2025 Simulator — Overview

This prototype demonstrates an integrated UI for exploring asteroid impact scenarios using NASA and USGS data. It focuses on clarity and accessibility while allowing room for more rigorous physics backends and richer visualizations (Three.js, Leaflet, D3).

Where to plug real data
  • NASA NEO API: Pull orbital elements and physical parameters in your Django backend and send them to the template.
  • USGS: Use DEM, tsunami zones, and seismic layers for map overlays.
  • Back-end simulation: Implement orbital propagation and impact physics server-side (Python) and return results for visualization.
